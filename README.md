# Newsdesk – Bludit Theme

Ein modernes Redaktions-Theme für [Bludit CMS](https://www.bludit.com), entwickelt
für Vereins- und Redaktionsseiten mit mehreren Rubriken und Autoren.

## Funktionen

- Header mit aufklappbarem Kategorien-Akkordeon
- Linke Sidebar mit Abteilungsliste
- Rechte Sidebar für Empfehlungen (konfigurierbare Rubriken)
- Mittlerer Nachrichtenfeed für aktuelle Artikel
- Automatische Archiv-Ansicht für ältere Artikel, nach Rubrik gruppiert
- Responsives Footer-Layout mit Rubriken- und Seitenübersicht

## Installation

1. Dieses Repository als ZIP herunterladen
2. Den Ordner-Inhalt nach `bl-themes/newsdesk/` in die Bludit-Installation kopieren
3. Im Bludit-Backend unter **Themes** das Theme **"Newsdesk"** aktivieren
